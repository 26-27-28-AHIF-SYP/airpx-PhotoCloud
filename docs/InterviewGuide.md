# Interview-Leitfaden: Cloud-Nutzung

## 1. Aktuelle Cloud-Nutzung

### A. Nutzen Sie aktuell einen Cloud-Service?

**Ja:**
1. Welchen Cloud-Service verwenden Sie?
2. Für welche Dateitypen nutzen Sie die Cloud (Fotos, Videos, Dokumente, Notizen)? Wie groß ist das Datenvolumen ungefähr?
3. Wie zufrieden sind Sie mit dem aktuellen Service?
   - Was würde Sie zu einem Wechsel bewegen?
   - Welche zusätzlichen Funktionen oder Verbesserungen müsste eine Alternative bieten?
4. Von welchen Geräten greifen Sie auf die Cloud zu (Smartphone, Tablet, PC, etc.)?
5. Wie organisieren Sie Ihre Dateien in der Cloud (nach Datum, Ordnern, Tags, etc.)?

**Nein:**
1. Haben Sie früher einmal einen Cloud-Service genutzt?
   - Wenn ja: Warum nutzen Sie ihn nicht mehr?
   - Was müsste eine Cloud-Lösung bieten, damit Sie sie erneut in Betracht ziehen würden?
2. Haben Sie schon einmal darüber nachgedacht, einen Cloud-Service zu nutzen?
   - Wenn nein: Was hält Sie davon ab?

## 2. Mediennutzung in der Cloud

1. Würden Sie Ihre Fotos gerne mit anderen teilen können?
2. In welcher Form möchten Sie Fotos teilen (Alben, einzelne Bilder, Links, etc.)?
3. Würden Sie KI-gestützte Analysen zum Sortieren oder zur Suche Ihrer Medien verwenden?
4. Bevorzugen Sie eine lokal betriebene KI-Lösung oder eine extern gehostete Lösung?

---

## 3. Hosting-Präferenz

- Bevorzugen Sie einen **lokal gehosteten** Cloud-Dienst (z. B. Nextcloud auf eigenem Server) oder einen **extern gehosteten** Service (z. B. Google Drive, Dropbox, iCloud)?
